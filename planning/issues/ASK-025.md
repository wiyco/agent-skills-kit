# ASK-025: Prepare CLI binary distribution and install documentation

## Goal

Design reproducible binary releases for users who do not have Rust installed.

## Context

Read `AGENTS.md`, `docs/architecture.md`, and `docs/testing.md` before implementation. This is a WIP, not-ready-for-use English-language OSS source preview, not a supported or published library/CLI. Source visibility is separate from crate and binary publication; see `docs/public-readiness.md` and `docs/release.md`.

## Scope

- Select verified build targets for Linux, macOS, and Windows, explicitly separating OS support from CPU/ABI support.
- Evaluate current cargo-dist or equivalent tooling from primary documentation; pin configuration and versions.
- Provide checksums, version reporting, smoke tests, and an artifact naming convention.
- Keep public upload/publish steps approval-gated and inactive during private development.
- Document cargo install and binary installation only after the corresponding release actually exists.

## Acceptance criteria

- [ ] Rehearsal artifacts execute --help/--version on their declared native platforms.
- [ ] Unsupported architectures/ABIs are not advertised.
- [ ] No public download URLs or successful-release badges are fabricated.
- [ ] Distribution uses the same reviewed library release rather than a divergent implementation.

## Verification

- Build rehearsal artifacts and validate checksums.
- Inspect workflow permissions and approval gates.
- Test installation instructions in isolated directories.

## Non-goals

Do not expand this issue into unrelated roadmap work.
