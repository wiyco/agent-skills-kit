# ASK-022: Add opt-in real-host discovery smoke tests

## Goal

Distinguish successful copying from a host actually discovering the installed skill.

## Context

Read `AGENTS.md`, `docs/architecture.md`, and `docs/testing.md` before implementation. This repository is private during development and is intended for a future English-language OSS release.

## Scope

- Provide a minimal benign test skill and per-host discovery-only smoke-test instructions.
- Run each host against an isolated project and temporary config/home where supported.
- Record exact host version, OS, scope, discovery result, and invocation limits.
- Keep paid API calls, account sign-in, and real-host downloads outside required PR CI unless explicitly approved.

## Acceptance criteria

- [ ] Core hosts have reproducible smoke-test procedures; actual execution is recorded separately from the procedure.
- [ ] The fixture never exfiltrates data or invokes skill scripts.
- [ ] The coverage matrix distinguishes docs_verified, resolver_tested, and host_smoke_tested.
- [ ] No unexecuted test is marked as passed.

## Verification

- Perform permitted discovery-only checks locally and attach sanitized results.
- Verify isolation before launching any host.
- Document hosts that cannot be tested without credentials or unsupported overrides.

## Non-goals

Do not expand this issue into unrelated roadmap work.
