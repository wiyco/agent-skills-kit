# ASK-012: Build native filesystem and security regression coverage

## Goal

Turn the safety contract into repeatable tests rather than relying on a happy-path copy demo.

## Context

Read `AGENTS.md`, `docs/architecture.md`, and `docs/testing.md` before implementation. This is a WIP, not-ready-for-use English-language OSS source preview, not a supported or published library/CLI. Source visibility is separate from crate and binary publication; see `docs/public-readiness.md` and `docs/release.md`.

## Scope

- Implement the matrix in docs/testing.md with temporary roots and explicit environment injection.
- Add fault injection and deterministic concurrency/race tests for planner and executor boundaries.
- Add property tests for skill names, path-rule containment, deterministic planning, and receipt round trips.
- Separate pure resolver tests, filesystem integration tests, and optional real-host discovery tests.
- Document filesystem-dependent exclusions without silently skipping critical cases.

## Acceptance criteria

- [ ] Native Linux/macOS/Windows CI covers copy, unchanged, conflict, permissions, Unicode/spaces, unsafe entries, overlap, and partial failure.
- [ ] A link/reparse-point privilege limitation is reported with a reason, not counted as a passed test.
- [ ] No test writes to real agent stores, user home, or external services.
- [ ] Security regressions include regression fixtures and run in required CI.
- [ ] An independent reviewer can reproduce failure scenarios from documented commands.

## Verification

- Run the full workspace test suite and all feature combinations the project supports.
- Exercise Windows-specific path behavior on Windows, not on Linux string emulation alone.
- Run targeted property tests with recorded seeds on failure.

## Non-goals

Do not expand this issue into unrelated roadmap work.

## Handoff

Open a focused PR with `Closes #<actual-issue-number>`. Report commands actually run, results, untested platforms, and any remaining risks. Do not merge or publish without maintainer approval.
