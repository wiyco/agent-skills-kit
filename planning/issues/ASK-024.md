# ASK-024: Rehearse the library release and document publishing controls

## Goal

Prepare a publishable library without publishing it automatically.

## Context

Read `AGENTS.md`, `docs/architecture.md`, and `docs/testing.md` before implementation. This is a WIP, not-ready-for-use English-language OSS source preview, not a supported or published library/CLI. Source visibility is separate from crate and binary publication; see `docs/public-readiness.md` and `docs/release.md`.

## Scope

- Finalize crate metadata, README, license files, repository links, documentation, feature policy, and MSRV.
- Check crate-name availability again immediately before release approval.
- Inspect cargo package output and compile an external consumer against the packaged artifact.
- Plan changelog/versioning and verify current crates.io trusted-publishing/release-automation support from official docs.
- Keep publish=false until a maintainer explicitly approves the release change; explain how to rehearse in a temporary copy.

## Acceptance criteria

- [ ] A packaging rehearsal is documented with actual commands and results.
- [ ] The artifact contains all runtime catalog assets and no local/private files.
- [ ] The license and dependency policy are approved.
- [ ] MSRV and native CI are green for the candidate commit.
- [ ] No real cargo publish or release tag is created by this issue without a separate explicit approval.

## Verification

- Run cargo package --list and a reviewed packaging/dry-run procedure in an isolated copy.
- Run rustdoc and external-consumer checks.
- Review semver changes and the release checklist.

## Non-goals

Do not expand this issue into unrelated roadmap work.

## Primary references

- https://doc.rust-lang.org/cargo/reference/publishing.html
- https://doc.rust-lang.org/cargo/reference/rust-version.html

## Handoff

Open a focused PR with `Closes #<actual-issue-number>`. Report commands actually run, results, untested platforms, and any remaining risks. Do not merge or publish without maintainer approval.
