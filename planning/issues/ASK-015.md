# ASK-015: Add interactive target and scope selection

## Goal

Let a user choose one or more hosts and confirm the exact installation destinations.

## Context

Read `AGENTS.md`, `docs/architecture.md`, and `docs/testing.md` before implementation. This repository is private during development and is intended for a future English-language OSS release.

## Scope

- Build an optional TTY selection flow for skill source, target tools, and scope.
- Show resolved destinations, unsupported targets, conflicts, and shared-reader warnings before confirmation.
- Cancel safely at every prompt and do not auto-select tools merely because a directory exists.
- Keep non-interactive behavior unchanged and make terminal dependencies CLI-only.

## Acceptance criteria

- [ ] Selecting Codex, Claude Code, and OpenCode installs only at the reviewed resolved write destinations.
- [ ] User cancellation produces zero writes before the apply step.
- [ ] Unsupported scopes cannot be selected silently.
- [ ] The same request produces the same plan in interactive and non-interactive modes.

## Verification

- Use injectable prompt input or a documented TTY test harness.
- Test cancellation and conflict confirmation.
- Perform a manual usability review without writing to real skill stores.

## Non-goals

Do not expand this issue into unrelated roadmap work.

## Handoff

Open a focused PR with `Closes #<actual-issue-number>`. Report commands actually run, results, untested platforms, and any remaining risks. Do not merge or publish without maintainer approval.
