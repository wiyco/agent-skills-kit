# Code of conduct

This policy applies to repository issues, pull requests, reviews, project discussions, and interactions undertaken on behalf of this project. It is an original project policy.

## Participation

Treat people with respect. Give specific, evidence-based technical feedback. Welcome questions and corrections, explain decisions, and respect contributors' time and privacy. Disagreement about code or design is acceptable; attacks on people are not.

Harassment, discrimination, threats, sexualized attention, impersonation, disclosure of private information, and repeated disruption are unacceptable. Do not use technical discussions to target or exclude people based on identity, background, ability, or experience. Do not retaliate against someone for reporting a concern.

## Reporting during private development

Authorized repository participants can open a [restricted repository issue](https://github.com/wiyco/agent-skills-kit/issues/new) for maintainer review while this repository is private. Include the relevant interaction and requested help, and omit unnecessary personal information or credentials. Check the audience before submitting: all repository members with issue access may read it. This channel is access-controlled, not confidential to a single recipient.

If that audience is unsuitable, or the concern involves the maintainer, do not disclose sensitive details there. Ask for an alternate private reporting channel through an existing trusted contact. No alternate contact has been verified by this project yet; that is a publication blocker, not an assurance that the current route fits every concern. A confidential public-contributor route and alternate contact must be approved and verified before the repository becomes public. The issue link must not be described as private after a visibility change.

## Response and enforcement

The maintainer reviews reports in context, limits unnecessary sharing, and explains any action to affected participants when practical. Available actions include asking for a correction, removing inappropriate content, ending an interaction, or restricting participation. Consider severity, repeated behavior, and safety; do not promise a fixed response time or confidentiality that the reporting system cannot provide.

Participants may request reconsideration with additional evidence through the same appropriate reporting channel. An independent appeal route has not yet been established and must be resolved before public collaboration is opened. Self-review by an automated agent does not replace the maintainer's judgment on conduct matters.
