## Checks

All commands below passed with the committed toolchain:

```sh
cargo generate-lockfile --offline
cargo fmt --all -- --check
cargo check --workspace --locked
cargo clippy --workspace --all-targets --all-features --locked -- -D warnings
cargo test --workspace --all-features --locked
cargo test --workspace --locked
cargo doc --workspace --no-deps --locked
rustc -Vv
cargo -V
rustup show active-toolchain
```

The executable integration test passed using the original tracked stdout fixture. The library and binary unit-test harnesses and library doctest harness also passed; they currently contain no test cases.

Two fresh temporary source copies, each without build output, also passed `cargo check --workspace --locked --offline` and `cargo test --workspace --locked --offline`. One retained the existing PATH with proto available. The other used only the existing Cargo bin directory and system executable directories; proto was confirmed absent from PATH. Both selected 1.99.1 from their copied toolchain file. This tests plain-rustup operation using the existing installed toolchain, rather than provisioning another user account or machine. Temporary copies were removed afterward.

`cargo metadata --no-deps --format-version 1 --offline` confirmed two Edition 2024 members, disabled publication for both, no external dependencies, no features, and no declared MSRV. `git diff --check` passed.
