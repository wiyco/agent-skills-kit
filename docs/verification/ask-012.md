# ASK-012 security regression evidence

This document records the native-backend checkpoint and its revision-specific measurements. Subsequent CLI and host-discovery work is implemented separately: see [CLI usage](../cli.md), [actual opt-in host results](host-discovery.md) and the [current technical checkpoint](release-readiness.md). Those later results do not retroactively expand the native safety claims below.

This matrix links the reviewed [threat model](../threat-model.md) to executable tests. It describes bounded evidence, not a security certification. Native backend support follows [ADR 0006](../adr/0006-native-copy-safety.md): Linux/macOS and Windows local NTFS now have successful native copy regressions. Windows successful copying is mandatory; resolver, codec or refusal tests alone cannot satisfy it. [Windows backend review](windows-backend.md#public-dispatch-and-verified-evidence) records exact merged candidate SHAs/CI/QA and the separate public dispatch gate.

## Reproduction and isolation

Use the committed Rust development pin and locked dependencies. From the repository root:

```sh
cargo fmt --all -- --check
cargo check --workspace --all-targets --all-features --locked
cargo clippy --workspace --all-targets --all-features --locked -- -D warnings
cargo test --workspace --all-features --locked
RUSTDOCFLAGS='-D warnings -D missing-docs' cargo doc --workspace --no-deps --locked
```

Required CI runs native Ubuntu, macOS and Windows jobs, plus independent Rust 1.85.0 MSRV/stable checks and quality/title gates. There are currently no optional Cargo features. No testing dependency was added for the fixed-seed generators. See [the testing guide](../testing.md#reproducible-seeded-properties) for seeds, case counts and exact targeted commands.

Every filesystem fixture exclusively creates its own temporary root and injects home/project context. Linux's additional tmpfs fixture exclusively owns a child of `/dev/shm`; it does not mount anything. Tests never execute skill content, use real skill stores/credentials, change HOME or call host/model services. A trusted Rust test child is used only for supervised process termination. Synthetic catalog URLs and receipt digests are test data, not host documentation or actual file hashes.

A missing capability is not a passed support test: socket, setuid, ACL and Windows directory-link fixture creation assert that the required condition was actually established. Permission-limited macOS sandbox runs can strip setuid bits; those runs fail and must be rerun in a suitably scoped native environment rather than counted as success. APFS rejects invalid UTF-8 filenames with EILSEQ; the test asserts that result and distinguishes it from Linux's successful opaque-name handling.

## Platform evidence and limits

PR #57, SHA `8d8cd4b7e693f4ced83413359b356a6936c29bd4`: [required native/MSRV/quality CI](https://github.com/wiyco/agent-skills-kit/actions/runs/38906162639) passed, Linux 137 tests/doctests, macOS 134, Windows 65. Native fixtures and interruption additions are in dependent PR #58, SHA `474c4dbffc5336ea3e3629cc31ddcaadee2bf444`; its final CI evidence is recorded in the PR's separate QA Evidence comment. The documentation layer also runs the required matrix on its own final SHA.

Local verification uses macOS 15.8.1 ARM64 on APFS, Rust/Cargo 1.99.1 via existing proto, with all formatting/compilation/Clippy/strict rustdoc checks and 136 tests/doctests passing after the native additions. Linux-only tmpfs and Windows-only reparse tests are not reported as locally executed. Native runner versions/filesystem observations belong to the exact CI logs and QA comment, not an assumption about future `*-latest` images.

This native-backend evidence is deliberately limited: it does not establish real-host discovery, all-filesystem guarantees, network filesystems, power-loss recovery, production-credential or public-release testing. The later CLI, expanded catalog, opt-in host results and release checks have their own evidence linked above. Untested matrix portions remain explicit rather than being silently skipped or described as passing.
