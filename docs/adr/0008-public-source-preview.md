# ADR 0008: WIP source visibility is separate from library and CLI publication

Status: accepted under explicit maintainer direction on 2026-10-17 JST (2026-10-16 UTC); preparation tracked in #93.

The maintainer intends to make the repository public personally to develop with public standard GitHub-hosted CI runners. The agent prepares the source, Issues, Project text and documentation but does not change repository or Project visibility. Project #10 remains private. No billing, purchase, release, package publishing or binary distribution action is authorized.

Publish the source only as **WIP — not ready for use**. There is no supported library/CLI release, installer or user support. Documentation and native tests describe implemented development behavior, not readiness for real user skill directories or universal host support. Keep `publish = false` and all CI/merge safeguards. M3/M4 remain incomplete; source visibility does not close ASK-026 or authorize M5.

The maintainer explicitly defers confidential reporting arrangements, an alternate conduct contact and independent appeals at this source-preview stage. This supersedes ADR 0005's requirement to establish them before any visibility change. They remain required before opening public contribution intake or publishing a supported library/CLI. Do not invent addresses, advertise unenabled GitHub private reporting, solicit sensitive public issues or claim a verified response process. Security and conduct policies must describe the actual unavailable/deferred routes. The code of conduct still applies to project interactions.

Public standard GitHub-hosted runner usage is free under GitHub's documented billing model; larger runners and other chargeable services are separate. Public visibility does not guarantee an account-level runner restriction is resolved, replace final-revision CI, or authorize weakening protection. The audit and maintainer handoff in docs/public-readiness.md distinguish changes possible while private from post-transition checks and unresolved merge prerequisites.
